# 🚀 Landing Page - Oasis Infobyte Internship

A modern, responsive, and visually polished landing page developed as part of the **Oasis Infobyte Web Development & Designing Internship - Level 1, Task 1**.

The project focuses on creating a clean user interface using semantic HTML5 and modern CSS3 layout techniques without using JavaScript.

---

## 📌 Project Overview

This landing page is designed to demonstrate fundamental front-end development skills including structured HTML, responsive layouts, CSS styling, typography, navigation, content organization, and visual consistency.

The website follows a modern landing-page structure with a sticky navigation bar, hero section, feature/content sections, call-to-action elements, and footer.

---

## 🎯 Objective

The objective of this task is to build a visually polished static landing page that demonstrates:

- Clean HTML5 structure
- Modern CSS3 styling
- Responsive web design
- Flexbox/Grid-based layouts
- Consistent visual branding
- Proper spacing and typography
- Mobile-friendly design
- User-focused page organization

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure and semantic content |
| CSS3 | Styling, layout, responsiveness and animations |
| Flexbox | Responsive component alignment |
| CSS Grid | Structured content layouts |
| Google Fonts | Typography |

> **JavaScript is intentionally not used**, as required by the Level 1 Task 1 specification.

---

## ✨ Features

### 🧭 Sticky Navigation
- Fixed/sticky navigation bar
- Multiple navigation links
- Easy access to different sections
- Responsive navigation layout

### 🎨 Hero Section
- Strong headline
- Supporting subheadline
- Primary call-to-action button
- Modern visual presentation

### ⭐ Content Sections
The landing page contains multiple structured sections to present information clearly, such as:

- Features
- About/Information
- Testimonials or supporting content

### 📱 Responsive Design
The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices

CSS Flexbox/Grid and responsive media queries are used to maintain the layout at different screen widths.

### 🎯 Consistent Visual Design
- Consistent colour palette
- Structured spacing
- Clear typography hierarchy
- Rounded UI elements
- Modern cards and sections
- Balanced visual composition

### 🔗 Footer
The footer contains placeholder contact and social links for a complete landing-page experience.
